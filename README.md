# Frigate 应用（中国大陆优化版）

这是专门针对中国大陆地区优化过的 Frigate 应用仓库，内置 HuggingFace、GitHub 等模型下载源的国内镜像，无需特殊网络即可正常下载所需模型。

## 安装

点击下方按钮：

[![打开你的 Home Assistant 实例并显示添加应用仓库对话框（预填特定仓库 URL）。](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FDesmond-Dong%2Ffrigate-hass-addons)

或者在 Home Assistant 中，进入 _设置_ > _应用_ > _应用商店_ > _..._ > _仓库_，将 `https://github.com/Desmond-Dong/frigate-hass-addons` 添加到列表中。
