# Frigate Apps

## Installing

Click on the button below:

[![Open your Home Assistant instance and show the add app repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FDesmond-Dong%2Ffrigate-hass-addons)

Or, in your Home Assistant, navigate to _Settings_ > _Apps_ > _App Store_ > _..._ > _Repositories_ and add `https://github.com/Desmond-Dong/frigate-hass-addons` to the list.
